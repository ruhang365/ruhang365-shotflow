# Frozen visual inputs

These seven PNG files are the exact visual inputs used by the isolated RC2
Quick Entry forward test. Their SHA-256 hashes are frozen in
`../protocol-v04-rc2.json`.

Only accepted or historical final frames are included here. Raw provider video
and private run metadata remain outside Git. The frames are published under the
repository's case-media terms (CC BY 4.0, to the extent rights can be claimed),
with AI-platform provenance disclosed by the corresponding case records.
