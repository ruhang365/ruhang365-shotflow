# ShotFlow evidence cases

These three original cases are pre-registered A/B experiments, not finished performance claims.

| Case | Role | Primary continuity stress |
| --- | --- | --- |
| [The Sky Mender](sky-mender/) | Flagship spectacle | identity, prop hand, open motion, weather light |
| [Storm Deck](storm-deck/) | Physical action | prop ownership, screen direction, inertia, geography |
| [Obsidian Bloom](obsidian-bloom/) | Fictional product film | silhouette, cap geometry, reflection, liquid state |

Each case freezes its baseline Clip 02 prompt before Clip 01 is generated. The ShotFlow Clip 02 prompt cannot exist until an accepted Clip 01 has been observed.

See [GENERATION_APPROVAL.md](GENERATION_APPROVAL.md) for the credit boundary and exact attempt budget.
